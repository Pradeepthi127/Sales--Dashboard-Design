Task 8: Simple Sales Dashboard Design
--- Objective
Create a basic interactive dashboard to visualize sales performance by product, region, and month using Tableau or Power BI.

---Tools Used
Tableau (for dashboard creation)

-----Dataset
Superstore_Sales.csv

Columns used: Order Date, Region, Category, Sales, Profit

---Dashboard Features
Line Chart: Sales trend over months (Order Date converted to Month-Year)

Bar Chart: Sales comparison across regions

Donut Chart: Sales distribution by category

Slicer: Interactive filter by Region

Color Coding: Highlights top-performing regions/categories

---Insights
The West region recorded the highest sales in Q3.

Technology category had the largest contribution to total sales.

Sales have shown a consistent upward trend over the months.

Central region had the lowest profit margin despite moderate sales.

---Outcome
Gained hands-on experience in building an interactive and visually clean sales dashboard to support business insights.
